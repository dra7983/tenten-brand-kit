# Typography

---

## Primary Typeface — Helvetica Neue

Helvetica Neue is TEN:TEN's primary typeface. Designed in Switzerland in 1957, it carries genuine Swiss heritage — the same tradition that produced the movements TEN:TEN restores. It is not used because it is neutral. It is used because it belongs here.

**Approved weights:** Light (300) and Medium (500) only.
- Light for display, headlines, and contexts where type needs to breathe.
- Medium for body copy, captions, UI elements, and anywhere the type needs to hold at smaller sizes.
- No Bold. No Black. No Thin. Weight restraint is part of the voice.

**Web fallback stack:** `"Helvetica Neue", Helvetica, Arial, sans-serif`

---

## Secondary Typeface — Baskerville

Baskerville is TEN:TEN's secondary typeface, used for long-form editorial content: movement histories, restoration notes, longer product narratives, and any context where the brand needs warmth, depth, or a reading pace that Helvetica Neue cannot provide.

Baskerville predates Helvetica by approximately 200 years. Together they span nearly three centuries — a quiet reference to the brand's relationship with time.

**Use Baskerville for:**
- Movement history pages
- Extended product narratives
- Editorial features and longer-form writing
- Pull quotes when set in longer editorial pieces

**Do not use Baskerville for:**
- UI elements
- Navigation
- Captions and metadata
- Short-form copy or social content

**Web fallback stack:** `Baskerville, "Baskerville Old Face", "Goudy Old Style", Georgia, serif`

## Casing Rules

**Title Case throughout.** Every word capitalised in headlines, subheads, navigation, product names, and UI labels.

**The logotype is the only exception.** TEN:TEN is always set as TEN:TEN — all caps, with colon — as a fixed mark. This is not a casing style to be replicated elsewhere. It is a mark.

**Never all caps in running copy.** Not for emphasis, not for headlines, not for labels.

**Never fully lowercase.** Not for brand voice, not for social copy, not for anything.

## Typographic Hierarchy

| Role | Typeface | Weight | Notes |
|---|---|---|---|
| Logotype | Helvetica Neue | Bold + Medium | Fixed mark — see `logo.md` |
| Display / Hero | Helvetica Neue | Light | Large scale, generous tracking |
| Section Heads | Helvetica Neue | Medium | Title Case |
| Body Copy (short) | Helvetica Neue | Light | Product descriptions, captions |
| Body Copy (long) | Baskerville | Regular | Movement histories, editorial |
| UI / Navigation | Helvetica Neue | Medium | Small scale, readable |
| Metadata / Captions | Helvetica Neue | Light | #AAAAAA, smaller scale |

## Tracking and Spacing

Display type (large headlines) should be set with generous letter-spacing — the brand breathes even in editorial density. Body copy tracks normally. Never artificially condense or expand letterforms.

Line height for body copy: 1.5–1.6x the type size. Editorial content reads better with room.
