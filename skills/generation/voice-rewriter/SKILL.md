# Skill: Voice Rewriter

Rewrite any text in TEN:TEN's voice.

---

## What this skill does

Takes existing copy — from another brand, a draft, a brief, a competitor, a press release, anything — and rewrites it so it sounds like TEN:TEN.

---

## Files to attach

- `brand/foundation.md`
- `brand/voice.md`

---

## Instructions for Claude

Read the attached `foundation.md` and `voice.md` carefully. Then rewrite the provided text in TEN:TEN's voice.

**Process:**
1. Identify what the text is trying to say — the actual information or argument underneath the words.
2. Identify what register it is currently written in (heritage? corporate? hype? neutral?).
3. Rewrite from scratch in TEN:TEN's voice. Do not edit the existing text word by word — rewrite it.

**Non-negotiable rules:**
- Title Case throughout
- No exclamation marks
- No superlatives without evidence
- No heritage register: no timeless, heirloom, storied, legacy, craftsmanship (standalone), artisan
- Active voice, present tense where possible
- If the original text explains TEN:TEN as a heritage brand or positions it as luxury, remove that framing entirely

**After rewriting:**
Flag any claims in the original text that cannot be rewritten without more information (e.g. if the original mentions a specific movement calibre you don't have details for). Ask for that information before finalising.

**Also note:**
Whether the rewritten copy could be made shorter without losing meaning. TEN:TEN copy does not over-explain.
